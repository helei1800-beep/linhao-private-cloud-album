# 邻好私有云相册 · PrivateCloud Album

**把手机照片自动存到你自己家里的电脑硬盘上。** 不出存储、不占你的云空间、不靠广告。

- 官网：https://www.linhaotech.cn
- 常见问题（39 问）：https://linhaotech.cn/faq.html
- 电脑端（Windows）：微软商店搜「**邻好**」
- 手机端（安卓）：应用宝、华为、vivo、百度、荣耀等应用商店搜「**私有云相册**」

> 苹果手机（iOS）和 macOS 暂时用不了。

## 它是什么

在电脑和手机上装同一个软件，扫码配对之后，手机拍的照片和视频会自动同步到家里那台电脑的硬盘里。

配对和认证要经过服务器，**服务器只负责让手机和电脑牵上线**；照片和视频本身存在你自己的电脑硬盘上，不经过服务器、也不存在服务器上。

## 它不是什么

- **不是网盘**：我们不提供云存储，也不保存你的照片。存储成本（硬盘、电费）是你自己出的，所以我们不需要向你收会员费。
- **不是 NAS**：不用买专用设备。家里那台常开的电脑加一块硬盘就行。
- **不是"连不上公网也能用"**：配对和认证需要公网，公网断了就传不了。
- **不是全自动到无脑**：需要一台常开的电脑；电脑关机时收不到新照片（手机里的照片会等回到电脑所在网络后自动补传）。

## 适用与限制

| 项目 | 情况 |
|---|---|
| 手机端 | 安卓（Android）。各大应用商店搜「私有云相册」 |
| 电脑端 | Windows（微软商店搜「邻好」） |
| 苹果 | iOS / macOS 暂不支持 |
| 网络 | 配对与认证需公网；同 WiFi 环境下自动备份，不在家时回到电脑所在网络后自动补传 |
| 硬件 | 一台常开的 Windows 电脑 + 硬盘空间 |
| 账号 | 需要注册并登录账号（用于手机与电脑配对） |
